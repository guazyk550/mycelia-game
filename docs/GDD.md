## 2. Core Fantasy
> **实现状态**：✅ 已实现（贯穿全部系统）


你不是点击赚钱的资本家。你是一颗孢子。

从漆黑土壤里的第一根菌丝开始，你「看见」的世界只有化学梯度。你的强大不来自数量，
而来自**连接方式**——同样的节点，接法不同，产出差一个数量级。最终你成为行星生态的
神经系统：地表文明的兴衰取决于你愿不愿意继续供糖。

三个幻想支柱：
1. **从无到有的蔓延感**：网络图每一分钟都在变复杂，可视化本身是奖励。
2. **智慧的网络**：你不是在堆建筑，你是在设计一个会思考的结构。
3. **生态的双刃**：索取（分解）会枯竭土壤，给予（共生）会获得长期回报。

## 4. Core Loop（四层循环）
> **实现状态**：✅ 已实现


### Loop 1 · 秒级（0–5 秒）
资源沿连线流动、酶催化触发、出芽暴击（crit）、孢子爆发、土壤湿度微扰、
资源数字跳动、连线光点流动。**每次交互必须有视觉反馈**。

### Loop 2 · 分钟级（1–10 分钟）
铺节点 / 连线（拓扑决策）、切换配方、升级节点、签契约、市场买卖、处理事件。
玩家每分钟至少面对 1 个「资源该投哪里」的选择。

### Loop 3 · 小时级（30 分钟–3 小时）
解锁新基质层（表土 → 含水层 → 矿脉层 → 岩层 → 深菌地幔）、解锁共生物种、
解锁自动化层级、完成挑战、第一次孢子化（Prestige）。

### Loop 4 · 长期（3 小时–100 小时+）
孢子化 → 基因树 → 菌株重组 → 虫巢意识 → 行星共生 → 星际播种；
图鉴收集、成就、隐藏基质层、无限深菌层、平行生态。

## 5. Long-term Loop
> **实现状态**：✅ 已实现


```
资源增长 → 拓扑优化 → 解锁新基质层 → 新节点/新配方 → 新瓶颈
   ↑                                                      ↓
菌株/基因强化 ← 孢子化(Prestige) ← 网络价值达标 ← 高级资源(核心/晶格)
   ↓
虫巢意识(自动化) → 行星共生(改规则) → 星际播种(平行生态, 终局循环)
```

永不中断的理由：拓扑优化是开放式问题（永远存在更优布局）；菌株 × 基因组合提供
重开动力；每层 Prestige 改变一次规则而不是只加数值。

## 7. Production System（拓扑即生产）
> **实现状态**：✅ 已实现


### 7.1 网络模型（v0.1 实现口径）
- 网络是一张**有向图**：节点（Node）是顶点，连线（Link）是边。
- 资源进入**全局库存**；连线的作用是**催化加成 + 决定结算顺序（拓扑序）**。
  这是为性能与可测试性做的刻意简化：完整物流模拟（每条边独立缓冲）会让性能与平衡验证成本
  上升一个量级，而收益主要体现在"布局空间"上，v0.1 先不做。
- 每条连线保留 `flux` 字段（通量约束预留位，v0.2 若启用物流模拟直接生效）。
- tick 结算：固定步长 100ms，按拓扑序（Kahn 排序）传播。上游产出在同 tick 内对下游可见；
  环内节点（Kahn 无法定序）改用 tick 起始快照判断输入 —— 全程确定性，同输入必然同输出。

### 7.2 节点类（class）
| class | 作用 | 示例节点 |
|---|---|---|
| extractor | 从基质层抽取 T0 资源 | 分解丝、掘进菌柄、吸水菌丝、感光菌帽 |
| metabolizer | T0/T1 → T1/T2 转化 | 糖化腔、酶腺、毒素腺 |
| sporifier | 生产孢子 / 扩散 | 孢子囊 |
| symbiont | 与地表物种交换 | 藻类共生体、根瘤接口 |
| transmitter | 生产信息素 / 电信号 | 信息素腺、电信号节点、中继 |
| special | 关键高级产出 | 菌核压机、核心腔、深菌钻、虫巢枢纽、镜像节点 |
| meta | T5 产出 | 星尘收集器、法则织机 |

### 7.3 反应矩阵（拓扑的收益来源）
每个下游节点有若干**配方槽 (recipe slot)**。连线本身不产生资源，但**上游节点的
`catalystTag` 会催化下游配方**：

```
catalystMul = max(rateMul of matching in-links) × min(1 + 0.02 × (inDegree - 1), 1.2)
匹配键 = (上游节点 catalystTag, 下游节点 class)；未命中则回落 (catalystTag, "*")，最后 default
```

- `fresh → metabolizer`：产能 ×1.15（新鲜原料直达）
- `cascade → metabolizer`：酶耗 −15%（酶级联复用）
- `cascade → transmitter`：×0.95（酶降解信息素——别把酶腺接到信息素腺上）
- `volatile → symbiont`：×0.75（毒杀共生体，寄生流的代价）
- `symbiont → *`：×1.05 且负面事件强度 −15%
- `neural → special`：×1.30（全游戏最高的单条催化倍率）
- 完整 30 条规则见 `data/catalyst-matrix.json`

**玩家优化的是「谁连到谁」，而非单纯堆数量**——同样 20 个节点，布局不同产出可差 3–10 倍。

### 7.4 基质枯竭（Soil Health）
每块地块有 `richness`（0–100%）。抽取类节点持续降低本块 richness：
```
richness -= extractRate × DEPLETION_K × (1 - repairBonus)
yieldMul  = 0.35 + 0.65 × (richness / 100)      # 枯竭下最低 35%
```
修复菌丝 / 轮作科技可恢复。**这是「风险流」与「后期治理」的底层张力**。

### 7.5 生长与扩张
扩张新节点消耗 `spore` + `sugar`，成本随网络规模按 `cost(n) = base × 1.18^n` 增长。
地块按基质层解锁，深层地块 richness 更高但初始接入成本更大。

## 10. Market System（菌市）
> **实现状态**：✅ 已实现（动态价格、卖压与深度）


- 每种可交易资源有 `price`，随玩家**净流量**反向移动（产量↑ → 价格↓）。
- 价格用均值回归过程：`p_{t+1} = p_t + θ(μ - p_t) + σ·ε_t`，θ≈0.05，σ≈0.03。
- 玩家可：囤货 / 抛售 / 加工后出售 / 等待；市场事件（§11）会造成跳空。
- 蜜露是主货币；深层资源需先解锁「菌市通道」。
- 反套利：同一资源 60 秒内重复大额交易手续费递增（防止无脑刷）。

## 14. Prestige（4 层，逐层改规则）
> **实现状态**：✅ 已实现（5 层：P1 重置 + P2–P5 跃迁）


| 层 | 名称 | 重置内容 | 货币 | 规则改变 |
|---|---|---|---|---|
| P1 | 孢子化 Sporulation | 网络、T0–T3 资源、节点升级 | 孢子基因 sporogene | 解锁基因树（机制节点） |
| P2 | 基因重组 Recombination | 上述 + 基因树 | 世代印记 strain | 菌株改变**开局规则**（自带节点/减益） |
| P3 | 虫巢意识 Hive Mind | 上述 + 菌株锁 | 虫巢积分 hivePoint | 跨区网络 + 自动化规则引擎 + 镜像网络 |
| P4 | 行星共生 Planetary Symbiosis | 上述 | 法则 law | 改写全局转换公式、季节轮转 |
| P5 | 星际播种 Panspermia（终局） | 全部 | 星尘 stardust | 平行生态：每颗新星球有一套不同规则的资源表 |

**孢子收益公式**（初版，待模拟器校准）：
```
networkValue = Σ(node.investedCost) × (1 + linkValueBonus) × topologyFactor
topologyFactor = 1 + 0.05 × ln(1 + catalystUses)
sporogeneGain = floor( max(minGain,
      (networkValue / networkValueBase)^0.55 × strainMul × (1 + geneBonus) × challengeMul × maturity ) )
maturity = clamp(sqrt(本轮时长 / 600), 0.2, 1)    # 10 分钟满额，低于则按平方根打折
```
- `networkValueBase`（=1.5e5）为早期调参旋钮，由模拟器标定（见 docs/balance/report.md）。
- `maturity` 是防刷分机制：本轮不足 10 分钟就重置，收益按平方根打折（最低 20%）。
  没有它时模拟器实测机器人 7 天孢子化 3000+ 次（每轮约 3 分钟），Prestige 退化为刷分循环。
- 收益随等待时间递增但边际递减，且**不会因等待而翻倍碾压**（软上限 3× 单轮值）。
