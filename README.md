# 共生之网 · Mycelia

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

拓扑驱动的增量游戏（incremental / idle）。你是一颗孢子，从黑暗土壤里的第一根菌丝，
长成覆盖整个行星、与所有生命签订契约的地下网络。

核心创新：**把增量游戏的生产链从「一维列表」升级为「可优化、会枯竭、能签约的二维网络」** ——
玩家优化的不是"买第 N 个"，而是"怎么连"。

---

## 快速开始

```bash
npm install
npm run dev            # 开发服务器
# 或
npm run build && npx vite preview --port 4175   # 生产构建 + 预览
```

第一次玩建议直接开新局：底部导航的「孢子 / 挑战 / 法则 / 时间」是四个进阶入口，
开局不需要碰它们。

## 玩法速览

| 系统 | 一句话 |
|---|---|
| **网络** | 节点按网格摆放、连线成图，催化规则让"某种上游 × 某种下游"产生额外倍率 |
| **土壤** | 采集会消耗地块富饶度，枯竭会拖垮产量 —— 扩张与修复的取舍 |
| **菌株** | 6 种流派改写规则（腐生把土壤嚼碎、织网靠连线数、孢子靠高频重置） |
| **Prestige** | 5 层：P1 孢子化是唯一的重置，P2–P5 是消耗资源换机制能力的跃迁 |
| **挑战** | 30 条"改写规则"型挑战（禁用节点类、配方输入输出对调、矩阵被打乱……） |
| **法则** | 9 条生态法则消耗法则碎片永久改写**公式**（成本斜率、离线上限、事件频率） |
| **惊喜** | 时间银行、虚空菌床、镜像网络、共生回声、自定义催化规则 —— 都不写进教程 |
| **自动化** | 六级自动化 + IF/THEN 规则编辑器（P3 虫巢意识后规则槽 +2） |
| **离线** | 离线收益 + "离线期间发生了什么"报告；反作弊识别时间回拨与超长离线 |
| **自动化** | 六级递进（买升级 / 扩建 / 连线 / 优化 / 孢子化 / 规则引擎），会自动挑最高倍率的层、避开成环与缺料上游 |
| **手机** | PWA + APK；触控手势完整，竖屏为全屏画布 + 底部抽屉 |

```

│   │   ├── economy/     # 资源账本、配方结算、建造与购买
│   │   ├── network/     # 图结构、拓扑排序、网格占位
│   │   ├── progression/ # 事件/成就/任务/合成表索引
│   │   ├── prestige/    # 孢子化、Prestige 五层、菌株
│   │   ├── challenges/  # 30 条规则改写型挑战
│   │   ├── meta/        # 生态法则、时间银行
│   │   ├── automation/  # 六级自动化与规则引擎
│   │   ├── market/      # 动态价格
│   │   ├── offline/     # 离线结算与反作弊
│   │   ├── save/        # 序列化、校验和、版本迁移
│   │   └── state.ts     # 状态容器与初始化
│   ├── data/        # 数据加载（Node 用 fs，浏览器用 Vite JSON import）
│   ├── ui/          # Canvas 渲染 + 16 个 DOM 面板
│   └── sim/         # 无头经济模拟器（策略机器人）

```

## 手机上玩

```bash
npm run build && npx vite preview --host 0.0.0.0 --port 4175   # 手机浏览器访问 http://<电脑IP>:4175/
npm run build:apk                                                # 或打成 APK
```

- **PWA**：手机浏览器打开后「添加到主屏幕」，全屏运行且**离线可玩**（Service Worker 预缓存应用外壳）
- **APK**：Capacitor + Android SDK（详见 [`docs/MOBILE.md`](docs/MOBILE.md)，含手势对照表与已知问题）
- 手机操作与桌面不同：**单指拖动**=平移、**双指捏合**=缩放、**点两个节点**=连线、**长按 500ms**=菜单；
  竖屏是「全屏画布 + 底部抽屉」（点导航的「建造」「强化」切换，点「网络」回到画布）
- 存档**双写** localStorage + IndexedDB，被系统清理后能在启动时自动救回

### 调试与验证通道（URL 参数）

| 参数 | 作用 |
|---|---|
| `?fresh` | 忽略存档，开新局 |
| `?ticks=N` | 加载后同步跑 N 个 tick（无头验证用） |
| `?demo=秒数` | 用模拟器的「积极玩家」策略自动玩一段，快速查看中期局面 |
| `?stress=N` | 直接铺 N 个节点（绕过成本与层容量），用于性能测试 |

任一参数存在时，页面会把节点数/资源/布局尺寸/渲染耗时写入隐藏的 `#selftest` 元素，供无头脚本抓取。

## 工程约定

- `src/core/**` 与 `src/sim/**` 禁止 import DOM API，保证可无头测试与模拟。
- **平衡数值只能来自 `data/**.json`**；代码中的常量必须是结构性常量（tick 长度、批处理上限等）。
- 大数一律走 `src/core/math/scinum.ts`，禁止裸 `number` 跨数量级累加。
- 相对导入带 `.ts` 扩展名（Node 类型剥离与 Vite 均可解析）。
- 浏览器侧与 Node 侧共用同一套 `core`，因此**模拟结论对实际游戏成立**。
- **未实现的东西必须显式报错，不允许静默忽略**（挑战的规则集合、校验器的 kind 词表都按这条执行）。
- 派生索引（如催化矩阵）改写时优先"读时重建"，不就地修改全局数据表，避免多存档互相污染。

## 性能

| 规模 | 渲染中位帧时间 | 单 tick 逻辑 |
|---|---|---|
| 300 节点 | 1.20 ms | 1.40 ms |
| 1000 节点 | 3.00 ms | 2.76 ms |
| 2000 节点 | 5.90 ms | 5.34 ms |

（设计目标：1000 节点 ≥30fps；实测 ≈173fps）

## 开源仓库里没有的东西

为了让仓库保持轻量、且不夹带任何本机信息，下列内容**不在版本库里**，需要时按对应命令重建：

| 缺失内容 | 原因 | 怎么重建 |
|---|---|---|
| `node_modules/` | 依赖，体积大 | `npm install` |
| `dist/` | 构建产物 | `npm run build` |
| `android/` | Capacitor 生成的原生工程，含本机 SDK 路径（`local.properties`） | `npx cap add android` 后 `npm run build:mobile` |
| `release/*.apk` | 4.5 MB 二进制 | `npm run build:apk`，或直接下载 Releases 里的成品 |
| 存档 / 模拟输出（`saves/`、`sim-out/`） | 运行时数据 | 游玩或 `npm run sim` 自动生成 |
